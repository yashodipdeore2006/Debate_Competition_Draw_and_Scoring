# CA1 Submission Checklist

- [ ] Confirm the allocated title and scope with faculty.
- [ ] Personalise the proposal with student, roll number, university, and guide details.
- [ ] Obtain faculty approval.
- [ ] Compile `src/main.cpp` with a standard C++ compiler.
- [ ] Execute all test cases and record actual outcomes.
- [ ] Capture screenshots for create, duplicate rejection, view, search, tie/winner, and summary.
- [ ] Review UML and flowchart with faculty.
- [ ] Commit meaningful milestones to a personal version-controlled repository.
- [ ] Prepare to explain class, private members, static member, inline methods, friend function, object array, pointers, `this`, validation, unique key, and search.
- [ ] Disclose AI assistance in the report as required by the course guide.
